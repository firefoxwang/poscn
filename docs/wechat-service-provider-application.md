# 微信支付服务商（mch_id）申请步骤

> 适用范围：普通服务商模式（服务商代特约商户发起支付）。本文覆盖 **服务商 mch_id 申请** 与 **特约商户进件（申请 sub_mch_id）** 两大环节；证书、API key、AppID 绑定等开发参数配置不在本文范围内（见文末相关文档）。

## 一、前提条件

- 一个**已通过微信认证的服务号**。微信支付服务商 mch_id 的申请渠道**仅开放给认证的服务号**。
- 企业主体资质（营业执照等），用于服务号认证与服务商主体审核。

## 二、总体流程概览

```text
申请服务号并完成微信认证
        │
        ▼
服务号后台 → 微信支付 → 服务商申请 → 获得服务商 mch_id
        │
        ▼
登录服务商平台（pay.weixin.qq.com/partner/public/home）
        │
        ▼
为特约商户进件（服务商平台「特约商户管理」或 API 进件）→ 获得 sub_mch_id
        │
        ▼
特约商户完成签约 → 开通支付权限 → 完成入驻
```

## 三、申请服务商 mch_id（第 1 步）

1. **注册并认证服务号**：登录 `mp.weixin.qq.com`，注册服务号账号并完成**微信认证**（需要企业主体资质）。
2. **进入申请入口**：登录已认证的**服务号后台**，点击左侧导航栏的「微信支付」。
3. **选择「服务商申请」**，按页面流程填写申请资料并提交。
4. 审核通过后，获得**服务商 mch_id**，即具备微信支付服务商能力。

官方申请指引：<https://kf.qq.com/faq/120911VrYVrA150813MFFJZv.html>

## 四、登录服务商平台

获得服务商 mch_id 后，登录**服务商平台**：

- 地址：`pay.weixin.qq.com/partner/public/home`（合作伙伴平台）
- 作用：特约商户管理、产品开通、开发配置等。

## 五、特约商户进件（申请 sub_mch_id）

特约商户进件有两条途径：**服务商平台后台进件**（人工）或 **API 进件**（调用「提交申请单」接口，批量/系统化场景推荐）。流程如下：

### 5.1 服务商提交进件申请

- 收集特约商户资料，创建入驻申请单（API 进件调用提交申请单接口；后台进件在「特约商户管理」中创建）。
- 支持主体类型：**小微、个体工商户、企业、党政机关及事业单位、其他组织**。
- 填写资料包括：**主体信息、经营信息、结算规则、结算账户、超级管理员**。
  - AppID 在「经营信息」模块填写；优惠费率在「结算规则」模块填写。

### 5.2 商家核对申请单信息

- 创建申请单后，获取「特约商户签约链接」（建议转成二维码）发给申请单的**超级管理员（超管）**。
- 超管微信扫码后，关注「微信支付商家助手」公众号并核对联系信息；后续公众号自动推送申请进展。

### 5.3 微信支付审核

- 审核约 **1～3 个工作日**，服务商可通过「查询申请单状态」接口查询审核结果。

### 5.4 特约商户账户验证

审核通过后，根据主体类型与超管身份决定验证方式（未在 **10 天内**完成验证将自动驳回申请单）：

| 主体类型 | 超级管理员身份 | 账户验证方式 |
|---|---|---|
| 党政、机关及事业单位 | / | 上传盖章证明函（无需验证）或汇款验证（10 天有效期） |
| 个体工商户 | 法人/经营者 | 无需账户验证 |
| 个体工商户 | 负责人 | 法人扫码验证 |
| 企业 | 法人/经营者 | 无需账户验证 |
| 企业 | 负责人 | 汇款验证 或 法人扫码验证（二选一） |
| 其他组织 | / | 汇款验证 |

- 汇款验证：商户用指定户名的银行账户向财付通指定账户汇款指定金额，系统自动退款至汇款账户（等待 1～2 天到账）。
- 账户验证链接与签约链接一致，服务商获取后转二维码发给超管。

### 5.5 特约商户签约

- 申请单状态为「待签约」时，服务商获取「商户签约链接」发给超管。
- 超管扫码后按页面指引完成签约。

### 5.6 开通权限

完成签约后系统自动开通权限，约 **30 分钟内完成**：

- **小微**主体：自动授权服务商「付款码支付、JSAPI支付、Native支付」。
- **个体户、企业、机关及事业单位、其他组织**：按进件选择的经营场景授权：

| 经营场景 | 支付权限 |
|---|---|
| 线下门店场景 | 付款码支付、JSAPI支付、刷脸支付 |
| 公众号场景 | JSAPI支付 |
| 小程序场景 | JSAPI支付 |
| App 场景 | App支付 |
| 互联网网站场景 | JSAPI支付、Native支付 |

- 另默认授权服务商 **API 退款** 权限。

### 5.7 完成入驻

- 申请单状态为「已完成」即特约商户入驻完成，获得 **sub_mch_id**，默认与服务商 mch_id 建立父子授权关系。
- 若填写了结算银行信息，特约商户发起第一笔交易后，微信支付会汇款 0.01 元校验银行卡；失败时商家助手公众号会通知修改。

## 六、注意事项

- 服务商自身无法作为普通商户直接发起交易，发起交易必须传入特约商户 sub_mch_id 参数。
- 特约商户进件指引：<https://kf.qq.com/faq/140225MveaUz161013MZBBFV.html>；服务商入驻指引（收付通等场景）：<https://kf.qq.com/faq/161220iqeAfA1612202yeURB.html>
- 本文申请细节（表单字段、资质清单）以官方申请页面与 kf.qq.com 指引为准，知识库未收录逐项表单内容。
